⚡ AZ-900 Exam Tips
  • IaaS = most control, most responsibility
  • PaaS = focus on code & data only
  • FaaS = write functions, Azure handles the rest
  • SaaS = just log in and use it
  • Spot VMs = cheapest, but can be evicted anytime
  • Reservations = 1-3 year commit = up to 72% off
